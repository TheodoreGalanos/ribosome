Failure classification: a failed agent task is not automatically a library defect. Library failures include lost or unauthorized context, repeated effects, incorrect accounting and promotion of unverified claims into host-verified outcomes. A model can receive adequate evidence and still answer incorrectly or misuse tools. Systematic information loss caused by the built-in compaction policy is still library behaviour to investigate. Track failed task demonstrations separately from reproduced implementation defects; a model-reported `completed` disposition is not a passed independent evaluation.
