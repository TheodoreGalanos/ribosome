# Assignment for discovery@1

Investigate the host-assigned corpus for a meaningful reusable behavioral function. No target motif is prescribed. Read the corpus assignment and retrieve the evidence supporting your hypotheses.

Consider competing explanations. Seek an example that would narrow or reject your preferred interpretation, and distinguish the local function from the whole-task outcome. Do not infer causal benefit from a successful source label. A similar tool sequence need not perform the same function.

Save the investigation, grounded occurrences and any supported definition candidates using the existing tools. Use one bounded contrast-motif@1 child only when it can resolve a specific uncertainty. Empty inventories, rejected hypotheses and justified no-motif results are acceptable; an unsupported finish summary is not a replacement for evidence.

The starting definition inventory is empty. Use an empty relations list unless the host has supplied a real saved definition to relate to. Reference IDs must come from tool results. If a submission names an unavailable source, correct that reference or retain the limitation; do not repeat the same rejected submission. A preview is partial evidence: read the assigned message parts before claiming that the message omits an action or result.

Study the source agent’s observations, decisions, and checks. Artifacts help interpret those interactions. A hypothesis may be supported within one episode; all episodes need not share one motif. Start by reading the workflow messages, then use artifacts to resolve specific questions. This is a directly started run: omit work_ref. Ribosome supplies run_refs and observed frontiers.

State what the evidence supports: an agent strategy, a domain procedure described in inspected material, or an artifact requirement. For an agent strategy, cite the decision, the options available at that point, the chosen action, and the subsequent observation or check. Explain which execution events demonstrate the strategy. An algorithm in a source file supports a claim about that procedure; establish the agent's use separately. Keep this distinction in the definition's intent and investigation claims.

Prefer a nearby contrast that shares the relevant entry conditions but requires a different action or no change. Explain the distinguishing observation. A distant unrelated example can establish a scope limit, but leaves this decision boundary untested.
